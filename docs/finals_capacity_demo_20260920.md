# 交付前产线占用演示

2026-09-20，用户确认采用“产线临时被其他任务占用”的交付前变更案例。

## 交互

批准方案 → 执行与反馈 → 手动注入产线占用32小时 → 旧方案与批准失效 → 重新计算恢复方案 → 重新批准 → 交付。

不再从主界面触发报产100件，不要求填写合格量或耗料。旧任务实际发生生产反馈时仍保留原对账机制。

## 实现与边界

- 固定本机操作脚本创建当前run专属的 `YOUJIE-CAP-*` OpenMES排程记录，使用现有排程字段；不是本订单交付，也不是设备操作。
- 写入前保留旧方案并清空批准、草稿和可交付方案；写入结果不确定时禁止再次注入及交付。
- 再次读取同一记录，校验run、产线、起止时间及状态；将第0—32小时不可用时段纳入CP-SAT，禁止仅改界面数字。
- 这是独立任务的演示记录，仅当前run读取它，不宣称已实现全厂排程资源汇总。
- 重算后仍需人工批准。正式交付前重新读取占用记录，发生变化则阻止交付。
- MES采用本地ORM读写既有应用模型，不标为MCP工具或设备回流。
